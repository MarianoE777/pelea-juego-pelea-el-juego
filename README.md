Nombre y descripción del juego:
    pelea juego pelea el juego, es un juego de pea de dos jugadores
Integrantes del grupo.
    mariano esborraz
Tecnologías utilizadas.
    JavaScript, Node.js, Vite, Phaser
Instrucciones para ejecutar el proyecto.
    tener instalado node.js, instalar las dependencias con npm install, ejecutar el servidor de desarrollo con npm run dev y por ultimo habrir el link resultante en el navegador.
Controles del juego.
    jugador 1: W, A, D, shift jugador 2: up, left, right, space
Agentes de OpenCode utilizados.
    agente primario
Principales instrucciones o prompts empleados.
    los personajes deben tener una lógica de movimiento simplificada con las siguientes restricciones:
    1. Movimiento Horizontal: se movera solo a la izquierda y a la derecha usando las teclas de flechas y A y D.
    2. Movimiento Vertical: Solo puede saltar (moverse hacia arriba) usando la flecha arriba y W. Debe tener gravedad para regresar automáticamente al suelo.
Problemas encontrados y soluciones aplicadas.
    ninguna contratiempo.
